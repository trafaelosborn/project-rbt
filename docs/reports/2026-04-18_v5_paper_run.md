## Interpretation

This run is suitable to cite as the paper-facing `v5` production condition.

The main outcome is:

- `v5` reached an effectively resolved near-zero structural endpoint
- it did so under one frozen methodology, seed, and output line
- it halted natively by plateau rather than by manual interruption

At the same time, the run also shows a meaningful multi-axis tradeoff:

- structure converged dramatically toward the Latin target
- form peaked earlier than the final plateau endpoint
- family alignment remained above the source baseline but did not approach 1.0

That means the scientifically useful artifact is not just one corpus, but a
small family of preserved endpoints:

- final plateau endpoint
- best-form checkpoint
- best-structure checkpoint

Those remain the main preserved endpoints for post hoc validator-bank and
control-bank analysis.
